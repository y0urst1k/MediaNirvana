# MediaNirvana

# DataModel.vsdx
В файле DataModel.vsdx представлена модель данных (для наглядности)
Примечания к файлу: 
1)если сущность (табличка такая) не имеет внешних ключей(FK), то она считается независимой(или главной); 
2)сущности помеченные знаком ! - не сущности БД(базы данных), а перечисления, необходимые соответствующим элементам БД;
3)сущности, не имеющие своего Id - являются связующими, то есть реализации отношения многие-ко-многим (не путать с перечислениями из п.2).

# Build
Перед сборкой приложения следует установить все необходимые зависимости (включая пакеты Nuget). И воспользовавшись консолью менеджера пакетов, применить миграцию. 
Нюансы при миграции заключаются в следующем:
1)Если БД не существует в проекте (искать в инфраструктуре или главном модуле) и никаких файлов миграции нет (в инфраструктуре, в папке Migrations), то нужно создать (следует побеседовать с разрабом, кто знает команды EF).
2)Если БД нет, но присутствуют файлы миграции, то соберите и запустите приложение. Если не запускается продолжительное время или вылетает ошибка, касающаяся БД, то нужно применить миграции (опять спрос с того кто знает EF).
3)Если есть БД и миграции, то никаких проблем быть не должно. Поэтому просто собираем и запускаем. Если все же есть проблемы - вопросы к команде (отдуваются все).
