###MediaNirvana
___________________________________________________
##О проекте

Название: MediaNirvana  

Назначение: удобное ведение заметок о просмотренных фильмах, сериалах, музыке и других медиаматериалах.  

Цель: помочь пользователям сохранять и систематизировать впечатления от контента — фиксировать мысли, ставить оценки, создавать подборки любимых произведений.

##Структура проекта
Проект состоит из следующих модулей:

1. MediaNirvana — главный модуль, точка входа, содержит IoC.
2. RealiztionMVVM — реализация MVVM с Prism 9, включает INotifyPropertyChanged.
3. MainComponents — View и VM для отображения данных и переходов.
4. Infrastructure — модель данных, логика работы с БД, DTO.
5. Dialogs — диалоговые окна и их VM.
6. UI — словари ресурсов (стили, шаблоны, цвета).

_______________________________________________________
##Модель данных

Подробная схема представлена в файле DataModel.vsdx.

Примечания к модели:

1. Сущности без внешних ключей (FK) — независимые (главные).
2. Сущности с пометкой ! — перечисления, не таблицы БД.
3. Сущности без Id — связующие (реализация отношения «многие‑ко‑многим»).

##Сборка и запуск

#Предварительные требования

* Установленный .NET (соответствующей версии)

* Доступ к пакетному менеджеру NuGet

#Инструкция по сборке

1. Установите все зависимости через NuGet.

2. Примените миграции для настройки базы данных:

    * Варианты действий:

      * Если БД и миграции отсутствуют:

          1. Создайте миграции (требуется знание команд EF).

          2. Обсудите с разработчиком, ответственным за EF.

      * Если БД нет, но миграции есть:

          1. Соберите и запустите приложение.

          2. Если возникает ошибка, связанная с БД, примените миграции.

      * Если БД и миграции есть:

          1. Соберите и запустите проект.

          2. При проблемах — обратитесь к команде.

3. После успешного применения миграций запустите приложение.
